Questo script si occupa di leggere un ebook e estrarre un array di prime lettere di tutte le parole.
Al momento non gestisce i casi particolari, ma solo i casi principali.

Successivamente occorrerà gestire i casi particolari generando più risultati per ogni libro laddove emergano delle parole ambigue.

Prima di farlo occorre però completare l'elenco delle parole ambigue.
