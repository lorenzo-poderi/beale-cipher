Questo script si occupa estrarre tutti i casi particolari di parole ambigue al fine di individuare una logica con la quale capire cosa può essere considerato abiguo e cosa no.

Genera il file: list-of-special-words.json
Con tutte le parole speciali individuate.

Problema:
L'analisi non è stata fatta solamente sull'inizio del testo reale, ma anche su parti di libro che potrebbero contenere parole strane, metadati, ecc...
